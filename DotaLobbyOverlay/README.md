# Dota Lobby Overlay — обработка в памяти

Windows GUI для отображения состава Dota 2. Приложение не следит за папками дампов и не создаёт `.bin`-файлы. Оно принимает готовый состав игроков через локальный Windows named pipe `DotaLobbyOverlay.LiveRoster`.

## Что делает интерфейс
- После получения состава автоматически выводит окно поверх остальных программ.
- Первые пять ников показывает в «Команде 1», следующие пять — в «Команде 2», сохраняя порядок записей из пакета.
- Помечает «ЭТО ВЫ» только если интеграция передала идентификатор текущего пользователя и такой же идентификатор у игрока.
- Само приложение не пишет дампы, состав игроков или настройки на диск.

## Важное ограничение: необходима интеграция с NetHookAnalyzer2
Один EXE не может автоматически прочитать внутренний поток сообщений уже запущенного NetHookAnalyzer2 без точки интеграции. Файл `NetHookAnalyzer2Adapter.cs` — мост, который нужно подключить к месту в исходниках NetHookAnalyzer2, где уже декодировано сообщение GC с `CSODOTAStaticLobby` и данными команды. Пока этот мост не подключён, приложение останется в режиме ожидания.

Мост передаёт только одну строку JSON через локальный named pipe; он не создаёт дампы. Пример формата:

```json
{"players":[{"name":"Player 1","team":0,"slot":1,"accountId":"verified-id-1"}],"myAccountId":"verified-id-1"}
```

В реальном сообщении нужно передавать всех 10 игроков. Для пометки своего ника `accountId` и `myAccountId` должны быть одним и тем же подтверждённым типом идентификатора. Не подставляйте произвольные числа из protobuf.

## Что удалось установить по приложенному дампу
- SteamID64 локального пользователя присутствует в Steam-протокольном заголовке: `76561198900263438`.
- В объекте `CSODOTAStaticLobby` есть десять ников в нужном порядке; отдельный объект лобби содержит десять слотов, разделённых на две группы по пять.
- Однако в текущем захвате не удалось надёжно связать SteamID64 из заголовка с одним из десяти идентификаторов в объекте `CSODOTAStaticLobby`. Поэтому автоматическая отметка «ЭТО ВЫ» не должна угадывать игрока. Когда интеграция получит подтверждённое соответствие SteamID ↔ игрок, подсветка заработает.

## Сборка EXE
Требуется .NET 8 SDK на Windows:

```powershell
dotnet publish .\DotaLobbyOverlay.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

EXE появится в `publish\DotaLobbyOverlay.exe`.

Проект в этом окружении не был скомпилирован и протестирован. Включён GitHub Actions workflow для сборки Windows EXE после загрузки проекта в репозиторий.
